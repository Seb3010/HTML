# Proyecto chismografo
-Este repositorio sirve como bitacora de aprendizaje Aquí agrupo prácticas, ejercicios de lógica y pequeños scripts que voy creando mientras estudio.

## Estructura principal

- `index.html` — Página principal
- `inicio.html` — Página de inicio alterna
- `4-A.html`, `4-B.html`, `5-A.html`, `5-B.html`, `6to.html` — Páginas de contenido/ejemplos
- `terms.html` — Términos y condiciones
- `styles/` — Carpeta con archivos CSS:
  - `style_4-A.css`, `style_4-B.css`, `style_5-A.css`, `style_5-B.css`, `style_6.css`, `style_inicio.css`, `style_terms.css`, `style.css`

## Cómo ver el proyecto localmente

1. Abrir `index.html` directamente en el navegador.

O bien, servir los archivos con un servidor local (recomendado para evitar problemas con rutas):

```bash
# Desde la carpeta del proyecto
python -m http.server 8000
# Luego abrir http://localhost:8000
```
